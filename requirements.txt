# This file MUST stay pure ASCII. pip-requirements-parser decodes it with the
# locale codec (cp936/GBK on Windows zh-CN), so a single non-ASCII character
# -- a smart quote, an em dash, a CJK filename -- makes pip-audit and any
# other parser abort with UnicodeDecodeError on a contributor's machine.
#
# Install:  pip install -r requirements.txt
# Dev:      pip install -r requirements-dev.txt
#
# Python 3.11.x is required (see pyproject.toml [tool.mypy] python_version).
